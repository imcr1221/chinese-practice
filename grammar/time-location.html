一、表示“什么时候做什么”

谁 + 时间 + 做什么
我今天学习中文。
小明下午踢足球。
妈妈晚上看电视。
我们周末去公园。

时间也可以放在句子前面

时间 + 谁 + 做什么
今天，我学习中文。
下午，小明踢足球。
晚上，妈妈看电视。
周末，我们去公园。
💡 中文里，表示时间的词通常放在动作前面。

二、表示“在哪里做什么”

谁 + 在 + 地点 + 做什么
我在学校学习。
小明在公园踢足球。
妈妈在厨房里做饭。
爸爸在公司工作。
姐姐在图书馆看书。

不要把地点放在动作后面

❌ 我学习在学校。
✅ 我在学校学习。
❌ 小明踢足球在公园。
✅ 小明在公园踢足球。
💡 地点通常也放在动作前面。

三、时间和地点同时出现

谁 + 时间 + 在 + 地点 + 做什么
时间 → 地点 → 动作
我今天在学校学习中文。
小明下午在公园踢足球。
妈妈晚上在厨房里做饭。
我们周末在家里看电影。
⭐ 很好用的顺序：谁 → 什么时候 → 在哪里 → 做什么

四、表示“某个地方有什么”

地点 + 有 + 什么
教室里有很多学生。
桌子上有一本书。
冰箱里有一些水果。
公园里有很多树。
我在教室里学习。 → 谁在做什么？
教室里有很多学生。 → 什么地方有什么？
